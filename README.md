# MeteoApp

Android-приложение для отображения погодных данных и рекомендаций.

В проекте реализованы работа с погодным API, обработка данных, пользовательский интерфейс и сохранение информации.

## Технологии

- Java
- Android Studio
- API
- SQLite

## Возможности

- получение погодных данных через API;
- отображение информации о погоде;
- формирование рекомендаций;
- сохранение данных;
- работа с несколькими экранами приложения.

## Запуск проекта

Склонируйте репозиторий:

```bash
git clone https://github.com/SlavaSava-del/special-enigma.git
```

Откройте проект в **Android Studio**.

Дождитесь синхронизации Gradle.

Запустите приложение на эмуляторе или подключенном Android-устройстве.
